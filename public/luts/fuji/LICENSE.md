# FUJIFILM colour tables

These colour tables are derived from abpy's FujifilmCameraProfiles
(https://github.com/abpy/FujifilmCameraProfiles), which are licensed under
CC BY-NC-SA 4.0 (https://creativecommons.org/licenses/by-nc-sa/4.0/).

`scripts/build-fuji-luts.py` re-expresses each table as the change from
PROVIA/STANDARD to that simulation, so it can be applied to finished photos.

use only, so replace them if LORES is ever sold.
